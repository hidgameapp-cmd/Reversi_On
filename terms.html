この利用規約（以下「本規約」といいます）は、Hideki Games（以下「当方」といいます）が提供する iOS アプリケーション「リバーシオン」（以下「本アプリ」といいます）の利用条件を定めるものです。

第1条（適用）

  1. 本規約は、本アプリの利用に関する当方と利用者との間の一切の関係に適用されます。
  2. 利用者は、本アプリをダウンロードまたは利用した時点で、本規約に同意したものとみなされます。

第2条（定義）

本規約において、次の各号に掲げる用語の意義は、それぞれ当該各号に定めるところによります。

  1. 「利用者」とは、本アプリを利用するすべての方をいいます。
  2. 「対局」とは、本アプリ上で行われるリバーシの一局をいいます。
  3. 「オンライン対戦」とは、他の利用者と通信を介して行う対局をいいます。
  4. 「CPU対戦」とは、本アプリに実装されたコンピュータプログラムを相手として行う対局をいいます。
  5. 「レーティング」とは、オンライン対戦の結果に基づき当方が算出する数値をいいます。

第3条（利用料金）

本アプリは無料で提供されます。アプリ内課金および広告表示は行いません。ただし、本アプリの利用に必要な通信料金は利用者の負担となります。

第4条（アカウント）

  2. 利用者は、任意で Apple ID との連携を行うことができます。連携を行った場合、機種変更後もデータを引き継ぐことができます。
  3. Apple ID と連携していない状態で本アプリを削除した場合、アカウントおよびこれに紐づくデータを復元することはできません。 当方はこれについて責任を負いません。
  4. 利用者は、本アプリの「設定」画面からいつでもアカウントを削除することができます。削除されたデータを復元することはできません。

第5条（未成年者の利用）

利用者が未成年者である場合は、親権者その他の法定代理人の同意を得たうえで本アプリを利用するものとします。

  1. 利用者は、本アプリ上で表示される名称（表示名）を設定することができます。表示名は他の利用者に公開されます。
  2. 利用者は、次のいずれかに該当する表示名を設定してはなりません。

  4. 差別的、わいせつ、暴力的または公序良俗に反するもの
  5. 当方または第三者になりすますもの

  7. 当方は、前項に違反する表示名を、事前の通知なく変更または削除することができます。

第7条（禁止事項）

利用者は、本アプリの利用にあたり、次の各号に掲げる行為を行ってはなりません。

  1. 法令または公序良俗に違反する行為
  2. 改造したクライアント、自動操作プログラム（BOT）、その他の不正なツールを使用して対局を行う行為
  3. 複数のアカウントを使い分けて対局し、レーティングまたはランキングを操作する行為
  4. 他の利用者と通謀して意図的に勝敗を決める行為（いわゆる談合）
  5. 対局中に意図的に放置し、または通信を切断することにより、対戦相手の時間を浪費させる行為
  6. 定型メッセージを繰り返し送信するなど、他の利用者を困惑させる行為
  7. 本アプリまたはサーバーに対し、過度な負荷をかける行為
  8. 本アプリのリバースエンジニアリング、逆コンパイル、逆アセンブルその他の解析行為
  9. 本アプリの不具合を意図的に利用する行為、および発見した不具合を当方に通知することなく第三者に公開する行為
  10. 当方または第三者の知的財産権、名誉、その他の権利または利益を侵害する行為
  11. その他、当方が不適切と合理的に判断する行為

第8条（違反への対応）

  1. 当方は、利用者が前条に違反したと判断した場合、事前の通知なく、次の措置を講じることができます。
  2. 当該対局を無効とすること
  3. レーティングを調整または初期化すること
  4. ランキングへの掲載を取りやめること
  5. 本アプリの利用を一時的または恒久的に停止すること
  6. アカウントを削除すること
  7. 当方は、前項の措置により利用者に生じた損害について、責任を負いません。

第9条（対局および対局結果）

  3. オンライン対戦において対戦相手が見つからない場合、本アプリは CPU 対戦へ移行します。この場合、その旨が画面に明示され、当該対局はレーティングに反映されません。
